## محوّل ملفات إكسل (`convertisseur-excel.html`)

تطبيق يعمل داخل المتصفح (بدون إنترنت وبدون تثبيت) لتحويل ملف إكسل بالفرنسية إلى ملف إكسل جديد بترتيب أعمدة معيّن.

**طريقة الاستعمال**
1. افتح الملف `convertisseur-excel.html` في المتصفح (Chrome / Edge / Firefox). يجب أن يبقى مجلد `lib` بجانبه.
2. اختر ملف الإدخال. يُكتشف سطر العناوين تلقائياً وتُطابَق الأعمدة الفرنسية
   (Nom, Prénom, Date de naissance, Prénom du père, Nom du conjoint, Nombre d'enfants…) مع أعمدة الإخراج.
3. راجع جدول "شكل ملف الإخراج": غيّر العناوين، رتّب الأعمدة (▲ ▼)، أضف أو احذف أعمدة.
   يمكن دمج عدة أعمدة في خانة "الصيغة" مثل `{Nom} {Prénom}`، و`{#}` للرقم التسلسلي.
   ويمكن أيضاً أخذ الشكل مباشرة من ملف إكسل نموذجي (سطر العناوين فيه).
4. اضغط "تصدير ملف الإكسل".

الإعدادات تُحفظ تلقائياً في المتصفح، ويمكن حفظها في ملف JSON وفتحها لاحقاً.
ملف تجريبي: `exemples/exemple_entree.xlsx`.
